# E1G2 saturation sample notes

- Data source: ignored PRADAN raw and calibrated E1G2 ZIPs for observation `20260227T1239538758`, plus the official `data/pradan/iir.zip` calibration archive.
- Command: `uv run --no-project --with numpy --with matplotlib python scripts/probe_iirs_saturation_sample.py`.
- Sample definition: 16 integer line indices generated by evenly spacing indices 0 through 12,209 inclusive. Read every sample position (0 through 249) in each line and only summarize E1G2-valid bands. No random seed or train/validation/test split applies.
- The compressed BSQ streams were consumed sequentially by band. The script retained the selected lines for calculation and wrote per-band CSV, summary JSON, and PNG figure under this module.
- Candidate saturation count is calibrated radiance `>=` official per-band `Saturation` value. Candidate dynamic-range count is paired raw count `>=` official per-band `Dynamic_Range` value. These comparisons are exploratory, not confirmed detector flags.
- The LUT check applies per-band/per-sample gain and offset to raw counts, then compares with calibrated radiance divided by 1000 as specified by the SIS. It is an internal consistency check.
- The table-only follow-up applies mode-specific LUT coefficients to each valid band's `Dynamic_Range` count, then compares median predicted mW radiance with the `Saturation` field under two unit scenarios. E1G2 saturation rows are 1-based; E3G2 rows are 0-based. The script maps both to 1-based band numbers. Neither unit reading is treated as authoritative.
- Table check command: `uv run --no-project --with numpy --with matplotlib python scripts/check_iirs_saturation_table_vs_lut.py`. It writes `metrics/iirs_saturation_lut_table_check_by_mode.csv`, `metrics/iirs_saturation_lut_table_check_summary.json`, and `figures/iirs_saturation_lut_table_check.png`.
- No raw data or cube archive was altered. No mask, reflectance, thermal correction, or scientific performance metric was generated. The CSV/JSON values and plots document diagnostic QA comparisons only.
