# Findings

- The 2021 IIRS–M³ radiance comparison covers 0.8–3.0 µm and scales both spectra to unity at 810 nm. Authors report broad shape agreement, with deviations near order-sorting-filter regions. This is a relative spectral-shape diagnostic, not an absolute scale validation. [LPSC 2021 abstract 2436](https://www.hou.usra.edu/meetings/lpsc2021/pdf/2436.pdf)
- The 2025 IIRS Level-2 method describes thermal-emission correction, apparent reflectance, photometric normalization, and empirical-line calibration using the Apollo 16 site and RELAB sample spectrum 62231 resampled to IIRS bands, followed by comparison with M³ over Mare Nubium. This is the strongest published route found for an independent reflectance-scale check, but it requires a scene covering Apollo 16 and does not validate the current E1G2 strip. [LPSC 2025 abstract 1876](https://www.hou.usra.edu/meetings/lpsc2025/pdf/1876.pdf)
- The 2025 independent Level-0 recalibration uses the ISRO LUT, saturation radiance and CCD dynamic range, then destripes. Its authors note differences from ISRO Level-1, including around 3 µm and beyond 4 µm, because they omit OSF radiance adjustment and keystone correction. Treat it as a reproducible method comparator, not as an authoritative mask or equivalent calibrated reference. [LPSC 2025 abstract 1644](https://www.hou.usra.edu/meetings/lpsc2025/pdf/1644.pdf)
- A 2025 EGU abstract reports a comparison between IIRS-derived temperatures and corresponding Diviner data by matching IIRS pixels using ground control points and acquisition local time; it says the temperatures are comparable for a particular period and identifies causes of mean differences. This can support a temperature-product check when matched coverage and conditions exist, but it is not an independent radiance-scale check because the IIRS temperature derives from IIRS radiance. [EGU abstract EGU25-691](https://doi.org/10.5194/egusphere-egu25-691)
- The PDS Imaging Node lists multiple official access sites for M³ volumes, including `CH1M3_0004` for Level-2 reflectance. Exa located an official JPL data-node index at `planetarydata.jpl.nasa.gov/img/data/m3/CH1M3_0004/`. Fetching that endpoint in this environment still failed strict TLS certificate validation, so the mirror is identified but its cube was not retrieved. [PDS M³ volumes](https://pds-imaging.jpl.nasa.gov/volumes/m3.html), [official JPL archive index](https://planetarydata.jpl.nasa.gov/img/data/m3/CH1M3_0004/)
- Exa found a second documented official route: the USGS IMG-hosted PDS4 M³ bundle at `https://pdsimage2.wr.usgs.gov/Chandrayaan_1/`. The conversion repository identifies this as the bundle distribution URL, but the current host returns 404 for the bundle root and probed volume/product paths. NASA Open Data lists the dataset but reports no downloadable resources. These routes did not yield binaries. [PDS4 conversion repository](https://github.com/MillionConcepts/m3-conversion), [NASA Open Data record](https://data.nasa.gov/dataset/ch1-orb-moon-m3-4-l2-reflectance-near-ir-spectral-imgs-v1-0-00272)
- The NASA PDS Geosciences Node ODE REST API provides an alternate metadata path: `results=fl` returned the complete label text and file inventory for `M3G20090206T010833_V01_RFL`; `results=m` returned its ODE detail/files-page URLs. The label confirms a global 304-sample × 27,796-line × 85-band float32 cube, invalid constant -999.0, thermal-correction flag `Y`, and source location file `M3G20090206T010833_V03_LOC.IMG`. ODE lists the RFL binary at 2,700,001 KiB, but the binary link remains hosted at the JPL Imaging Node, where strict TLS validation still fails. See [`m3_candidate_ode_metadata.json`](m3_candidate_ode_metadata.json) and the [official ODE REST manual](https://oderest.rsl.wustl.edu/ODE_REST_V2.1.6.pdf).
- **P1 binary-access gate is blocked in this environment:** the ODE label and inventory are available, but both RFL and source location images are needed to measure per-pixel valid overlap. JPL binary TLS validation fails and the documented USGS PDS4 route returns 404. Do not substitute product-footprint or sparse-control-point counts for this result.
- The existing M³ candidate remains a sparse geometry-grid ranking only. Until the product cube is acquired, actual valid-pixel overlap and any spectral comparison remain unknown.
- User correction: the IIRS team has already been contacted without response. Further contact is not a next action. The project will pursue data-based checks and published methods.
- **Quality gates remain open:** guide-versus-label radiance units, Level-1 fill/mask semantics, independent absolute radiance scale, and actual M³ valid-pixel overlap. No candidate interpretation is promoted to a calibrated reflectance or mineral/hydration/ice result.
