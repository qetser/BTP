# M1 reference-data findings

- The E1G2 footprint at approximately 5.47°W–3.50°W and 6.53°S–26.86°N is a low-latitude strip. LROC lists a global WAC morphologic mosaic at 100 m/pixel, which is a candidate spatial reference. Its ground sampling is comparable in scale to IIRS, but mosaicking, illumination, and sensor differences require independent control-point review.
- The PDS M³ Level-2 archive describes products as pixel-located and reflectance-calibrated. The IIRS Level-2 literature also describes same-region M³ comparisons. This supports a future cross-instrument reflectance check after IIRS corrections, not a direct check of current Level-1 radiance.
- The public PDS ODE REST service's M³ `REFIMG` footprint-intersection query returned five Level-2 candidates for the E1G2 bounding box: IDs `M3G20090205T211213_V01_L2`, `M3G20090205T225833_V01_L2`, `M3G20090205T233034_V01_L2`, `M3G20090206T010833_V01_L2`, and `M3G20090206T030351_V01_L2`, all orbit 1080. Their metadata are saved in [`m3_overlap_candidates.csv`](m3_overlap_candidates.csv) and generated by [`query_m3_overlap.py`](../../../scripts/query_m3_overlap.py).
- ODE's footprint-intersection result is a candidate selection only. Although label review is complete, usable pixel masks and common IIRS/M³ coverage still need review; no cube has been downloaded.
- Review of all five PDS3 labels shows `CH1:THERMAL_CORRECTION_FLAG = Y`, 304 samples, and 85 bands in each L2 reflectance product. Each label describes reflectance values as unitless with stored 1.0 representing 100% reflectance and declares a special-pixel value of -999.0. The scenes contain 9,310–27,796 lines. This confirms product type and approximate data dimensions, not valid common pixel count or suitability of the correction for local IIRS.
- The smallest candidate by line count is `M3G20090205T233034_V01_RFL` (9,310 lines), but line count alone does not make it the best reference. Use the pixel-location data to select based on common footprint and usable coverage before downloading its cube.
- Counting the 1,476 E1G2 sparse geometry coordinates inside ODE product footprints ranks `M3G20090206T010833_V01_L2` first: 1,033 points (69.99%). `M3G20090205T225833_V01_L2` contains 703 points (47.63%); the other counts are 259, 5, and 0. This is a point-sample screen only, not overlap area or valid-pixel coverage. Values are in [`metrics/m3_control_grid_overlap.csv`](metrics/m3_control_grid_overlap.csv), plotted in [`figures/m3_control_grid_overlap.svg`](figures/m3_control_grid_overlap.svg).
- Acquired an E1G2-sized grayscale crop from `WAC_GLOBAL_O000N0000_100M.PYR.TIF` using TIFF byte ranges. The local crop is 824 x 10,230 pixels at 100 m/pixel with 20 km margin; 164 tiles and 10,747,904 raster bytes were fetched. The full 1.62 GB pyramid was not downloaded. Metadata and a rerunnable acquisition script are linked in the [summary](summary.md).
- The WAC raster and IIRS coordinates have not been registered. No held-out residual, overlap area, reflectance error, or pass/fail result has been computed. WAC can inform spatial registration only, not IIRS radiometric calibration.
- Chauhan et al. (2025) use Apollo 16 ground observations for calibration and same-region M³ for comparison. Apollo 16 is outside the current E1G2 footprint and cannot serve as this scene's local ground target.
- A recent preprint reports SIFT registration of IIRS strips to LRO WAC, but it is not peer reviewed. It is a candidate method to evaluate, not validation evidence for this scene. Prefer held-out control points and report residuals rather than adopting the paper's performance claim.
