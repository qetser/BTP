# Plan

Read `project.md`, `tasks/lessons.md`, `tasks/task_plan.md`, and the relevant scientific gate in `docs/m1_m3_plan.md`.

For a new substantial task, update `tasks/task_plan.md` with a concrete goal, small phases, and observable exit checks. Resume an existing phase when it already covers the request. Keep decisions traceable in `tasks/findings.md` and completion notes in `tasks/progress.md`.

Treat the user's current instruction as authoritative. A plan is a working record, not a reason to delay routine authorized work. If a scientific gate cannot pass, record the evidence and limit the claim.
