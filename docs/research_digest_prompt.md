# M1–M3 research digest prompt

Use this prompt for a manually run or user-scheduled research digest. Set its cadence and destination before enabling a recurring task.

> Review newly available primary sources relevant to Chandrayaan-2 IIRS calibration, calibrated PRADAN product availability, M³ cross-validation, lunar hyperspectral labeling, and M1–M3 baselines. Compare each finding with `project.md`, `docs/m1_m3_plan.md`, and `tasks/findings.md`. Report only items that change a method, data-access decision, risk, or experiment. For each item, provide a direct source link, publication date, event date when different, the precise evidence, and a proposed action. Mark interpretations as inferences. If nothing material changed, say so. Do not edit scientific pass criteria, download bulk data, or make external posts without an explicit request.

Before scheduling, decide: cadence, source scope, output destination, whether the task can access this checkout, and how the first two digests will be reviewed. [Official scheduled-task guidance](https://learn.chatgpt.com/docs/automations).
