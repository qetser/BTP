# Word list

These are the project meanings. Some words have broader meanings in other fields.

| Word | Plain meaning |
| --- | --- |
| **Band** | One wavelength measured by the instrument. Think of one layer in the stack of IIRS images. |
| **Calibrated radiance** | A detector measurement converted to physical light units. It is still not reflectance. |
| **Detector count** | The number recorded by the sensor before conversion to physical light units. |
| **E1G2 / E3G2** | Instrument settings written in an IIRS label. The settings affect which wavelength bands are useful. |
| **Fill value** | A special number used to mark data that are missing or unusable. The E1G2 calibrated-product label does not state one. |
| **Footprint** | The patch of the Moon covered by an observation. |
| **Geometry** | Where an image pixel is on the Moon and how the instrument viewed it. |
| **Image tie** | A matching surface pattern in two images. It helps compare alignment but is not a surveyed lunar location. |
| **Independent check** | A test that uses a separate source of evidence. It can show whether a result works beyond the data used to create it. |
| **IIRS** | The Imaging Infrared Spectrometer on India's Chandrayaan-2 spacecraft. It records many wavelengths for each image location. |
| **LUT** | Look-up table. Here it provides numbers used to convert E1G2 detector counts to radiance. |
| **M³** | The Moon Mineralogy Mapper on India's Chandrayaan-1 spacecraft. We may compare its reflectance images with IIRS after both data sets pass review. |
| **Mask** | A map that marks which measurements can be used and which must be ignored. |
| **PDS4 label** | An XML file that describes a science product, such as its dimensions, units, wavelengths, and checksum. |
| **QUB** | The binary file that stores the image cube values. The XML label describes the QUB. |
| **Radiance** | Measured light arriving from the Moon, reported in physical units. |
| **Reflectance** | A measure of how much light the surface reflects compared with the light that reaches it. |
| **RMSE** | Root mean square error. A single number that summarizes differences between positions or values. Large errors affect it more than small errors. |
| **Saturation** | When a sensor reaches a limit and can no longer measure a stronger signal correctly. |
| **Spectral cube** | An image stack with one layer for each wavelength. Each location has a list of measurements across the wavelengths. |
| **WAC** | Wide Angle Camera on NASA's Lunar Reconnaissance Orbiter. Its lunar images are used here as a map reference. |
| **Weak label** | A broad hint about a place, such as its mapped rock type. It does not prove the exact material at each image pixel. |
